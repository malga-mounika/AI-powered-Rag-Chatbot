🤖 RAG Chatbot — AI Document Knowledge Hub

An AI-powered **Retrieval-Augmented Generation (RAG) chatbot** that allows users to upload PDF documents and ask questions about their content.

The application extracts text from uploaded PDFs, splits the text into smaller chunks, generates vector embeddings, stores them in ChromaDB, retrieves the most relevant chunks for a user's question, and uses Gemini to generate a contextual answer.
